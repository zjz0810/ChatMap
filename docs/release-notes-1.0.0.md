# ChatMap 1.0.0 — ChatGPT 长对话专项版

ChatMap 1.0.0 是面向 ChatGPT 网页长对话的独立维护版。重点修正滚动加载、索引刷新、节点顺序和跳回原文时的身份匹配问题。

## 修复与改动

### ChatGPT 消息顺序和重复节点

- **向上滚动加载旧消息后，前面的节点不再冻结，旧消息也不会作为“最新消息”追加到队尾。** 现在根据稳定消息身份和相邻窗口重叠关系合并历史，并按时间顺序重新编号。
- **重复问题仍能区分。** 两条内容完全相同但来自不同原始消息的问题保持为两个节点；同一消息后续流式补全则更新原节点，不再新增副本。
- **旧的或不完整的读取不会覆盖较新的完整索引。** 部分虚拟列表快照不能静默重排或删掉未出现在当前视口的历史节点。
- **刷新索引会重新扫描并重建图谱。** 完整扫描按顺序生成节点，并在结束后恢复聊天页面原来的滚动位置。这个动作会重新生成图谱节点；手工笔记或布局需要保留时，请先导出 ChatMap JSON。
- **跳转按原始消息身份定位。** 同文问题不会再靠相似文本猜测；找不到准确目标时会明确失败。

### 界面调整

- 更名为 ChatMap，更新扩展名、图标、文档和发布包。
- 默认浅色主题调整为雾白、浅灰和克制蓝；降低画布网格对比度。
- 降低画布最小缩放比例，以便缩小查看更大的图谱。
- 按维护者当前要求，隐藏节点上的 AI 按钮。

## 适配范围

- **本版重点：ChatGPT 网页版。** 长对话索引、顺序、完整刷新和精确跳转改动以 ChatGPT 为目标。
- Gemini、DeepSeek、Claude、Kimi、豆包、Qwen、Grok、GLM/Z.ai 等内置适配仍保留，但各站能力和浏览器验证程度不同；请以 README 的“支持站点能力表”为准，不将 ChatGPT 的修复范围扩大解释为所有 LLM 都已修复。
- 需要支持其他 LLM 网站或服务，欢迎在本仓库提交 Issue 联系维护者，并附平台名称、浏览器和复现步骤。

## 安装与备份

- Chrome / Edge：从 `release/chatmap-v1.0.0.zip` 下载并解压，通过 `chrome://extensions` 或 `edge://extensions` 的开发者模式加载解压目录。
- 刷新索引会重新生成节点。重要的手工整理内容请先通过 Files 导出 ChatMap JSON。
