## 2026-07-13 Native-index adaptation

- Implementation: a clean-room MAIN-world observer passively captures Grok's existing conversation-response GET/POST traffic from `document_start`, including incremental streamed response bytes. Extraction never calls a scrolling API.
- Identity and echo handling: the structured response graph uses origin, conversation ID, human `responseId`, assistant `responseId`, and `parentResponseId`. Assistant `query` prompt echoes are ignored for answer construction, repeated response objects are deduplicated by backend ID, and longer streamed messages enrich the same turn identity.
- Deterministic navigation: TurnMap reveals only an exact mounted `response-<responseId>`, `data-response-id`, or `data-message-id` target. A missing or mismatched element returns an explicit failure without text matching, neighbor selection, or scroll search.
- Domain boundary: `grok.com` and `x.com` caches are origin-scoped. The native response implementation is evidence-backed only for `grok.com`; `x.com/i/grok` redirected the anonymous browser probe to X login, so the X shell remains on safe mounted-DOM fallback.
- Automated evidence: synthetic fixtures cover prompt echo, duplicate nested response objects, identical prompt text with distinct IDs, streaming enrichment without identity replacement, strict origin isolation, exact target revalidation, wrong-ID and missing-target safe failure, adapter routing, and eager passive capture.
- Browser and bundle evidence: the current public `grok.com` page loaded successfully, and its production bundles exposed `/c/:conversationId`, `GET/POST /rest/app-chat/conversations/:conversationId/responses`, plus `responseId`, `sender`, `message`, and `parentResponseId`. The public composer still required registration before an answer, so authenticated long-conversation and early off-screen acceptance could not be completed.
- Capability decision: retain `blocked-auth` at the mounted-DOM tier. The structured index is implemented, but promotion requires authenticated long-conversation proof that the full response graph is captured and exact distant turns remain mounted or have a verified deterministic revive path.
