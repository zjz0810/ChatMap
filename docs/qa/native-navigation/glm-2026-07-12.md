# GLM / Z.ai Browser QA

- Original smoke date: 2026-07-12
- Variant investigation: 2026-07-13
- Result: `smoke-verified` at the mounted-DOM tier
- Original extension result: exactly one launcher was injected and the side panel mapped one anonymous redacted prompt and completed assistant text as one mounted turn.

## ChatGLM / 智谱清言

- `https://chatglm.cn/main/alltoolsdetail` returned a slider-verification page before the application shell. No account state, conversation response, stable message identity, long history, or deterministic off-screen target could be inspected.
- The ChatGLM profile is now host-scoped to `.detail .item .question/.answer`; it no longer shares Z.ai selectors or cache state.
- Capability remains mounted-DOM only and blocked for new browser acceptance. No native upgrade is claimed.

Evidence: `screenshots/glm-chatglm-initial-2026-07-13.png`.

## Z.ai

- An anonymous guest page created a synthetic QA conversation at `/c/<conversation-id>` without accessing user history.
- The observed `POST /api/v1/chats/new` payload used `chat.history.messages`, `history.currentId`, `parentId`, and stable UUID message ids. The mounted DOM used exact `message-<UUID>` and `message-<UUID>-start` ids under `#messages-container`.
- The assistant shell mounted under a distinct UUID, but the reply flow then opened slider verification. Completed streaming, repeated-prompt browser behavior, long/off-screen history, conversation switching, and deterministic unmounted revival could not be accepted in the real browser.
- TurnMap now passively indexes captured Z.ai chat create/detail request/response pairs, follows only the active parent chain, keeps repeated prompts distinct by UUID, filters reasoning/planning fields and segments, isolates cache by variant + host + conversation, and reveals only an exact mounted UUID. Missing targets fail explicitly without text matching or scroll search.

## Capability decision

The external `glm` site remains `smoke-verified` at the mounted-DOM tier. Z.ai has evidence-gated structured-index support, while ChatGLM remains blocked before the app shell; one host's evidence is not used to promote the other. Full native status still requires per-host long-session, repeated-prompt, streaming, conversation-switch, scrollTop-invariance, and off-screen target evidence.

Evidence: `screenshots/glm-mapped-smoke.png`, `screenshots/glm-extension-baseline.png`.
