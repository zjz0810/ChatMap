## 2026-07-13 Native-index adaptation

- Implementation: a clean-room `document_start` MAIN-world observer passively captures Doubao history and current-chain responses. The content adapter builds a stable conversation/message index, retains ghost turns when virtual rows unmount, enriches longer streamed answers, and performs no extraction scrolling.
- Identity: conversation ID plus message ID is authoritative. Repeated prompts remain separate even when their text is identical, and switching conversations clears the previous conversation's native mapping.
- Deterministic navigation: an exact mounted `[data-message-id]` is revealed directly. Otherwise TurnMap asks the mounted React virtual-list controller for the message's native `block_<message-id>` key, waits a bounded interval, and reveals only after the remounted element's message ID matches exactly.
- Safe failure: a missing controller, rejected key, timeout, or neighboring remount returns an explicit failure. There is no scroll scan, offset guessing, or text-similarity fallback.
- Automated evidence: synthetic fixtures cover full indexing, ghost retention, repeated text with different IDs, streaming enrichment, transient empty responses, conversation isolation, deterministic virtual requests, exact-ID revalidation, timeout/wrong-ID safe failure, adapter routing, and eager passive capture.
- Browser probe: the final unpacked `0.9.1` build loaded on the real anonymous Doubao page under Playwright Chromium with the early MAIN-world observer, exactly one TurnMap launcher, and no page errors. Login was still required for conversation evidence; current first-party bundles exposed the history/current-chain message routes, stable message IDs, and React virtual-list `scrollToRow` / `scrollIntoItemsById` controllers used by the evidence-gated bridge.
- Capability decision: retain `blocked-auth` at the mounted-DOM tier. The native path is implemented, but full indexing and distant off-screen jump are not promoted until logged-in long-conversation acceptance confirms unchanged extraction scroll position and exact one-shot arrival.
